# Platform Support Matrix

**Status:** Current
**Last updated:** 2026-09-06

The canonical Batchalign matrix is
[Platform Support in the public book](../book/src/batchalign/reference/platform-support.md).
It owns platform tiers, wheel and smoke coverage, Windows lifecycle limits,
and the experimental desktop classification. This entry point preserves
existing links without duplicating that matrix.

Chatter owns the CHAT core, CLI, LSP and grammar in
[its own repository](https://github.com/TalkBank/chatter). Their platform policy
is not defined by the Batchalign workspace.

See [Release Contract](RELEASE-CONTRACT.md) for compatibility promises and the
[release checklist](../book/src/batchalign/developer/release-checklist.md) for
artifact and smoke-test gates.
